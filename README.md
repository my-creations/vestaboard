# Vestaboard

A minimal Vestaboard-style clock website.

## What it does

Vestaboard recreates a split-flap display in the browser and keeps it synced to Lisbon time.

## Features

- 6 × 22 character grid
- Lisbon time (`Europe/Lisbon`)
- black background with white letters
- split-flap style animation
- toggleable sound

## Run locally

```bash
npm run dev
```

Open:

```text
http://localhost:4173
```
